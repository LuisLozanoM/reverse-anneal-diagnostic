# Figure-to-data map

Every quantitative result in the manuscript ([arXiv:2605.19381](https://arxiv.org/abs/2605.19381)) regenerates from the raw samplesets in this repository. This map links each figure to its producing script and key data paths.

| Figure | Producing script | Key data path |
|---|---|---|
| Fig. 1 | `scripts/figures/fig1_recompose.py` (composite of hand-drawn sub-panels) | `manuscript/figures/fig1{a,b,c}_*.svg` |
| Fig. 2 | `scripts/figures/generate_all_figures.py::fig3_subsystem` | `data/raw/phase4/scan_*` (legacy) and `data/raw/phase4/regen_fig2b_*` (overlay) |
| Fig. 3 | `scripts/figures/generate_all_figures.py::fig4_disorder` | `data/raw/phase4/scan_W*`, `data/raw/phase4/scan_crossover*`, `data/raw/phase4/regen_utc_system64` |
| Fig. 4 | `scripts/figures/fig6_thermal_marginal.py` (standalone, data-driven) | `data/raw/phase6_gibbs/phase3c_disorder_sweep/comparison.json` |
| Fig. 5 | `scripts/figures/generate_all_figures.py::fig5_baselines` | `data/classical/phase5/{exact_diag,glauber}/` |
| SI beta-sensitivity figure | `scripts/phase6_beta_sensitivity.py` | `data/raw/phase6_gibbs/beta_sensitivity.json` (regenerated byte-identically from the raw samplesets) |

Figure filenames in `manuscript/figures/` are historical and do not always match the published figure numbers; the mapping above is authoritative.

## Key derived artifacts

| Path | Contents |
|---|---|
| `data/raw/phase6_gibbs/*/comparison.json` | Per-condition memory order parameter and conditional-Boltzmann distances for every thermal-marginal sub-campaign (the 494-condition Advantage2 campaign and the 60-condition Advantage_system6.4 replication) |
| `data/raw/phase6_gibbs/beta_sensitivity.json` | Reference-temperature sensitivity of the relaxed-subset distance (the discrepancy-detector test) |
| `data/raw/phase4/*/spot_check_embedded.json` | Paired auto_scale on/off spot checks, chain-length and chain-break statistics |
| `data/analysis/probe_consistency.json` | beta_eff probe-bias consistency cross-check |

## Reproducing

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e .
pip install pytest && pytest tests/
python scripts/figures/generate_all_figures.py
python scripts/figures/fig6_thermal_marginal.py
python scripts/phase6_beta_sensitivity.py
```

No D-Wave account or QPU access is required for any of the above; a QPU account is needed only to regenerate raw samplesets from scratch with the `scripts/phase*/` drivers.
